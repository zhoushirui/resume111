# Third-party browser libraries

Bundled locally so the UI does not depend on CDN availability at startup.

- Tailwind CSS Play CDN 3.4.17: https://cdn.tailwindcss.com/3.4.17 (MIT)
- docx 7.3.0: https://unpkg.com/docx@7.3.0/build/index.js (MIT)
- FileSaver.js 2.0.5: https://cdnjs.cloudflare.com/ajax/libs/FileSaver.js/2.0.5/FileSaver.min.js (MIT)

Corresponding license files are included in this directory.
